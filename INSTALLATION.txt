Mission Hold Skipper, installation guide


What this is

An .asi plugin for GTA San Andreas and GTA III. It replaces the instant mission
scene skip with a hold to skip action: hold ENTER (or click the left mouse
button) and a small black circle in the bottom right corner fills with white.
Release early and nothing is skipped.

There is one file per game. Use MissionHoldSkipper.asi for San Andreas and
MissionHoldSkipperIII.asi for GTA III. Vice City is not supported yet.


Before you start

1. You need GTA San Andreas v1.0 US, or GTA III v1.0.

   For San Andreas, check the md5 of your gta_sa.exe, it has to be
   170b3a9108687b26da2d8901c6948a18 (14383616 bytes). On Windows, in a terminal
   opened in your game folder:
       certutil -hashfile gta_sa.exe MD5

   Downgraders exist if you are on 1.01, 2.00, or a Steam or Rockstar Launcher
   copy. The plugin refuses to touch any other version. It will not crash your
   game, it simply does nothing.

2. You need an ASI loader, either Silent's ASI Loader or Ultimate ASI Loader.
   If you already run other .asi mods, you have one.

3. Optional, and recommended if you play with a gamepad: install GInput for your
   game from
       https://cookieplmonster.github.io/mods/gta-sa/ginput/
   The pad works without it, but the button icon in the middle of the circle is
   drawn from GInput's own textures, so without GInput the prompt is text only.
   See "Using a gamepad" below.


Installing

1. Open the folder that contains the game exe, gta_sa.exe or gta3.exe.

2. Copy the two files for your game into that folder:
       San Andreas: MissionHoldSkipper.asi and MissionHoldSkipper.ini
       GTA III:     MissionHoldSkipperIII.asi and MissionHoldSkipperIII.ini

   If your setup uses a "scripts" folder for .asi mods, put both files in there
   instead. What matters is that the .asi and the .ini end up in the same folder
   and keep their names, otherwise the plugin runs with its built in defaults.

   Keep only one copy. Some loaders scan the game folder and a "scripts" folder,
   so the same .asi left in both places loads twice, and the second copy refuses
   to install and writes that to its log.

3. Start the game and begin any mission that has a cutscene.

4. Hold ENTER. The circle appears and fills up, then the scene is skipped. A
   single tap does nothing on purpose. The hold is 1.2 seconds on San Andreas and
   0.6 seconds on GTA III, where cutscenes are often only a few seconds long.


Checking that it loaded

A log file is written next to the .asi with the same name, so
MissionHoldSkipper.log or MissionHoldSkipperIII.log. After starting the game
once, open it. A healthy log looks like this:

    [info] mission-hold-skipper 0.2.0 loading, built for GTA SA 1.0 US
    [info] version check ok, screen 1920x1080
    [info] hooks installed, hold 1200 ms to skip

If instead you see a line about a byte mismatch, your gta_sa.exe is not the
supported v1.0 US build, and the plugin stayed inactive on purpose. On GTA III
the same job is done by a line about a call it could not find, which means the
build is not v1.0.

If there is no log file at all, the ASI loader never loaded the plugin. Confirm
the loader is installed and that the .asi sits in the folder the loader scans.


Changing the settings

Open the .ini for your game in any text editor. The values are read once when
the game starts, so restart the game after editing. The most useful ones:

    HoldMs=1200            how long the key has to be held, commented out by
                           default, which means 1200 on SA and 600 on GTA III
    Keys=ENTER,NUMPAD_ENTER,MOUSE_LEFT,PAD_CROSS
    Label=HOLD ENTER TO SKIP
    LabelPad=HOLD TO SKIP        shown while you are on a gamepad
    PromptDevice=auto      auto, keyboard, or pad
    PadIconMode=auto       auto, off
    PadIconStyle=auto      auto, ps, xbox
    FontStyle=-1           -1 keeps the game's own font
    RingRadius=18          size of the circle
    RingX=-1               -1 keeps it in the bottom right corner
    ShowHintBeforeHold=0   1 shows the prompt before you press anything
    LogLevel=info          set to debug for a noisier log

Every key is documented in README.md.


Using a gamepad

Holding a pad button works just like holding ENTER. Which button is up to you,
set it in Keys: PAD_CROSS, PAD_CIRCLE, PAD_SQUARE, PAD_TRIANGLE, PAD_L1, PAD_L2,
PAD_R1 or PAD_R2. This works with a plain DirectInput pad and with GInput, in
both games.

If GInput is installed, the button is also drawn as an icon in the middle of
the circle, with the progress sweeping around it. The icon is taken from
GInput's own textures in your models folder, and it follows GInput's
PlayStationButtons setting. Without GInput the prompt stays text only.

So if you play on a pad, installing GInput is worth it. Get the build for your
game from
    https://cookieplmonster.github.io/mods/gta-sa/ginput/
put it in the game folder, and the icon shows up by itself. Nothing has to be
changed in the ini for that, and the icon style follows whatever GInput is set
to. If you want to force it, use PadIconStyle=ps or PadIconStyle=xbox, or
PadIconMode=off to keep the prompt text only.

If the prompt shows the wrong device, set PromptDevice=keyboard or
PromptDevice=pad.


Uninstalling

Delete the .asi, the .ini and the .log for your game from the game folder.
Nothing else is modified. The plugin only patches memory while the game runs and
never writes to the game exe.


Troubleshooting

The prompt never appears at all.
   Check the log for "hooks installed". If it says another copy is already
   loaded, you have the .asi in two places, delete one.

The prompt never appears in some cutscenes but works in others.
   GTA III only offers a skip while the cutscene camera is in its flyby mode, and
   never for the ending cutscene. Mission scenes with a static camera have no
   skip in the game at all, so there is nothing to hold there. With
   LogLevel=debug the log says when a skip is on offer and for which scene.

The prompt appears but the scene never skips.
   Make sure you keep the key held for the whole duration. Lower HoldMs if
   1.2 seconds feels too long.

The circle sits in the wrong place.
   Set RingX and RingY in the ini. They are in 640x448 units and get scaled to
   your resolution. Use -1 for the default corner placement.

The game crashes on startup.
   Remove the .asi and confirm the game starts. If it does, report the issue
   with your log file and the md5 of your game exe.
